## Инструкция по запуску проекта.
1. Если до этого запускали прежние версии проекта, удалите файл `anime1c.db`
2. Загрузите зависимости `python -m pip install -r requirements.txt`
3. Запустите файл `init_db.py`. Можно ввести команду `python init_db.py`.
4. Запускайте `main.py`. Можно ввести команду для запуска `python init_db.py`.
